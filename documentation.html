THE SYSTEM IN ONE VIEW

Phone → NFC → Aliro → policy → lock.

The NFC transport is deliberately isolated from the protocol and the access policy. That means a different NFC frontend can be added without rewriting the Aliro transaction, and access rules can evolve without touching the cryptographic protocol.
