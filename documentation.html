Aliro HomeKey documentation

A practical reference for understanding, building, flashing and testing the Aliro HomeKey ESP32 reader.

Start here: If you are new to the project, follow Quickstart first. Then use the architecture and hardware sections to understand what the firmware is doing before debugging a transaction.

Introduction

What Aliro HomeKey is

Aliro HomeKey is an open-source ESP32 access-reader project. The system combines an ESP32, PN532 NFC hardware, Aliro credential processing and a configured access-control output. This documentation describes the engineering path from hardware to transaction.

Phone / credential
      ↓
PN532 NFC
      ↓
NFC transport / APDUs
      ↓
Aliro reader logic
      ↓
authentication + access decision
      ↓
Matter Door Lock / configured output

Quickstart

Run your first reader

  1. 01 · Hardware. Prepare an ESP32-WROOM-32 compatible board and PN532.
  2. 02 · Firmware. Build from source or obtain a supported release image.
  3. 03 · Flash. Enter ROM bootloader mode and flash the firmware.
  4. 04 · Configure. Connect the device and configure supported settings.
  5. 05 · Validate. Check serial logs, NFC detection and then the access-control path.

Installation

Build from source

Use an ESP-IDF environment compatible with the project revision.

git clone https://github.com/Ruhanpaco/Aliro-homekey.git
cd Aliro-homekey
idf.py set-target esp32
idf.py menuconfig
idf.py build

Flash firmware

Install firmware on the ESP32

For source builds, ESP-IDF can flash and monitor the board. Supported release images can be installed with the project browser flasher.

idf.py -p PORT flash monitor

Troubleshooting

Common failures

USB is visible, but bootloader connection fails

A visible USB-UART device does not prove the ESP32 is in ROM download mode. Hold BOOT, press and release EN/RESET, then retry. Check automatic-reset wiring if required.

Flashing succeeds, but firmware does not start

Check the ESP32 target, flash configuration, image and serial output. Make sure the image matches the board and release.

NFC starts, but the transaction does not complete

Separate NFC transport from credential processing and the final access-control endpoint. Inspect serial logs at each stage.

Contributing
