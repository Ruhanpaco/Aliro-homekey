01 · Introduction

What is Aliro HomeKey? #

Aliro HomeKey is an open-source ESP32 access-reader project. An ESP32 hosts the embedded application, a PN532 provides NFC communication, Aliro reader logic processes the transaction, and the configured access-control layer receives the result.

transaction flowALIRO
Phone / credential
      ↓
PN532 NFC frontend
      ↓
ISO 14443-4 / APDUs
      ↓
Aliro reader session
      ↓
authentication + access decision
      ↓
Matter Door Lock / configured output

03 · Installation

Build from source

Use an ESP-IDF environment compatible with the project revision. Then configure and build the target.

terminal
git clone https://github.com/Ruhanpaco/Aliro-homekey.git
cd Aliro-homekey
idf.py set-target esp32
idf.py menuconfig
idf.py build

08 · Testing

Validate one layer at a time

Start with USB and serial communication. Then verify firmware boot, PN532 detection, NFC transport, credential processing and finally the access-control output. This prevents one hardware symptom from being mistaken for a protocol failure.

09 · Troubleshooting

When the board refuses to cooperate

USB is visible, but the bootloader connection fails

A visible USB-UART device does not prove the ESP32 is in ROM download mode. Hold BOOT, press and release EN/RESET, then retry the connection.

Flashing succeeds, but the firmware does not start

Check the selected target, flash configuration, image and serial output. Make sure the firmware matches the board.

NFC is detected, but the transaction does not complete

Separate NFC transport from credential processing and the final access-control endpoint. Inspect serial logs at each stage.

10 · Development

Contributing to the project

Keep protocol, hardware and security assumptions explicit. Test changes on intended hardware and document behavior that differs between firmware versions.
