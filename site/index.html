Aliro HomeKey / ESP32 Flasher

Flash the firmware.

This browser tool uses Espressif's esptool-js over Web Serial. The most common connection failure is the ESP32 not being in ROM download mode, so this flasher now supports both automatic reset and a manual BOOT/EN recovery path.

Before connecting

  1. Use desktop Chrome or Edge.
  2. Connect the ESP32 with a data USB cable.
  3. If automatic reset fails, hold BOOT, press/release EN/RESET, then release BOOT.
  4. Choose the USB serial device when prompted.

Important

The flasher writes firmware and a generated development identity. Do not use a generated identity as a production access credential. Read the release notes before flashing.

Manual bootloader mode
Hold BOOT → press and release EN/RESET → keep BOOT held for about 1 second → release BOOT → click Manual bootloader connect.
