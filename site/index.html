Aliro HomeKey flasher

Generates a unique Aliro reader identity in this tab, packs it into an ESP-IDF NVS partition image, and writes it to an ESP32 over USB together with the firmware. Nothing is uploaded and no server is involved.

What this project is  ·  Source on GitHub

Your private keys never leave this tab

Key generation runs entirely in crypto.subtle, the browser's own crypto engine. This page has no backend: it is a static file on GitHub Pages, it makes no network request while flashing, and the generated private keys exist only in this tab's memory and in whatever you choose to download. Close the tab and they are gone — so save the bundle if you want to keep the identity.

Read this before flashing a door

  • There is no NFC chip driver yet. The reader boots, serves its web console and drives the lock GPIO, but cannot read a card.
  • The generated identity is a self-signed development identity, not a provisioned Aliro credential. No shipping wallet will accept it. It exists so the firmware and a test device can complete a transaction on a bench.
  • Writing the NVS image erases the stored configuration, the Wi-Fi credentials and the Aliro SDK's fast-transaction keys.
