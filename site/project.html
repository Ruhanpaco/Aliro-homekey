Aliro HomeKey

An experimental Aliro access reader for ESP32, connecting mobile wallet credentials to real-world access hardware.

Open browser flasherView source
v0.4 beta
Verified on ESP32-WROOM-32 + PN532 with Matter provisioning, NFC transactions and lock output. This is a research project, not a certified production access-control product.

The architecture

Aliro HomeKey puts the interoperability layer in Aliro while the ESP32 handles the physical reader, access decision, configuration and lock control.

Current capabilities

Aliro

Fast and standard transaction paths through Espressif's Aliro SDK.

NFC

PN532-based hardware validation on ESP32-WROOM-32.

Matter

Matter Door Lock integration with Aliro provisioning support.

MQTT

Lock state, tap events, commands and Home Assistant discovery.

OTA

Firmware updates with rollback support.

Configuration

Browser UI with NVS-backed hardware, network and system settings.

Observed transaction times

On the tested ESP32-WROOM-32 + PN532 setup, the fast transaction path completed in approximately 569 ms and the standard path in approximately 2047 ms, with the lock output driven at completion.
