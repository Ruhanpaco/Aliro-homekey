OPEN-SOURCE ACCESS CONTROL · ESP32

Put the access reader in your hands.

Aliro HomeKey is an open-source ESP32 reader exploring standards-based digital access across phone ecosystems. The project combines Aliro, NFC, Matter, a configurable web interface and real embedded hardware.

WHAT IT IS

A reader, not a vendor silo.

Aliro provides the common access protocol. The ESP32 supplies the embedded platform. The project supplies the glue: NFC transport, credential storage, access policy, lock output, provisioning, configuration and integrations.
