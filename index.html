OPEN-SOURCE ACCESS CONTROL · ESP32

One reader.
Open standards.

Aliro HomeKey is an open-source ESP32 reader built around Aliro, the Connectivity Standards Alliance's cross-wallet access credential standard — Apple, Google, and Samsung all speak it, so the reader isn't locked to one ecosystem.

WHAT IT IS

A reader, not a vendor silo.

Aliro provides the common access protocol. The ESP32 supplies the embedded platform. This project supplies the glue: NFC transport, credential storage, access policy, lock output, provisioning, configuration, and integrations.

01
⌁

Phone / credential

A wallet holding an Aliro credential — Apple, Google, or Samsung — begins the tap.

02
◌

NFC transport

A PN532 frontend carries the ISO 14443-4 interaction to the reader over SPI or I²C.

03
▣

Aliro reader

Espressif's Aliro SDK handles authentication, transaction state, and credential identity.

04
✓

Access control

This project decides whether a credential is allowed, then drives the lock output.

HONEST STATUS

What's verified, what's still open.

The docs separate what's implemented from what's actually been checked on hardware. That distinction matters more here than in most projects — this firmware opens a physical door.

verified on hardware

Apple Home + Aliro over Matter

Commissioned, credential provisioned, both transaction paths opened the lock. Home app lock/unlock, OTA rollback, MQTT and Home Assistant discovery all exercised on the same board.

known issue, disabled by default

Apple Wallet Express Mode

The ECP beacon that wakes a locked phone has twice been found to desync the NFC bus on real hardware. It's implemented but off by default until the root cause is actually fixed, not just believed fixed.

untested

Google Wallet & Samsung Wallet

Samsung specifically needs a Matter-capable hub to administer the fabric — a bare Galaxy phone can't hold it. See the roadmap for what that actually requires.

builds, not hardware-tested

ESP32-C3 / ESP32-S3

CI builds and releases firmware for both, and both fit their OTA slot. Neither has been flashed to a real board by this project yet.

HOW A TAP WORKS

NFC in, decision out, lock fires.

Aliro transactions run ISO 7816 APDUs over ISO 14443-4 NFC. A device seen before uses the fast path; a new one runs the full handshake.

Phone / watch
      │  ISO 14443-4 NFC
      ▼
┌─────────────────────┐
│   nfc_transport      │  poll / activate / exchange
└──────────┬───────────┘
           │ APDUs
           ▼
┌─────────────────────┐
│    aliro_reader       │  session + authentication
└──────────┬───────────┘
           │ credential + result
           ▼
┌─────────────────────┐
│   access_control      │  identity + policy + lock
└─────────────────────┘
