HOW IT WORKS

Phone → NFC → Aliro → policy → lock.

A tap starts an ISO 14443-4 interaction. The reader authenticates the device, resolves its credential key slot, completes the transaction and hands the result to access control. The policy layer then decides whether the configured lock output should actuate.

01

Credential

A phone or watch presents an Aliro credential through the supported transaction path.

02

NFC transport

The NFC frontend polls, activates the device and exchanges APDUs with the reader stack.

03

Aliro session

Espressif's Aliro library handles protocol state, authentication and session processing.

04

Access decision

The credential key slot is checked before the lock output is allowed to actuate.

HONEST STATUS

Experimental hardware. Real progress. No fake certification.

The project distinguishes between code that compiles, hardware that boots, credentials that provision and a complete transaction that has actually been observed. Apple commissioning has been verified, while Google and Samsung wallets remain untested.
