FLASHING · ESP32

on the board.

There are several good ways to flash an ESP32. For this project, start with the release binaries and use the project's browser flasher when you want a simple USB workflow. For maximum trust and control, use Espressif's official tools.

Use the tool that matches the job.

Aliro browser flasher

Best for trying a published Aliro HomeKey build. It runs on this project's static site, uses Web Serial, and generates the development identity in the browser. No backend is involved.

RECOMMENDED WORKFLOW

Release → verify → connect → flash.

1 · RELEASE

Download from GitHub Releases

Use the project's release page rather than an unknown firmware mirror. Match the image to your board and read the release notes before flashing.

2 · BROWSER

Use Chrome or Edge on desktop

Web Serial requires a supported desktop browser and a secure HTTPS page. Safari and iOS browsers are not suitable for the browser flashing workflow.

3 · USB

Connect the ESP32 directly

Use a data-capable USB cable. Close other serial tools before connecting. If the board does not appear, try the BOOT button while connecting.

4 · FLASH

Erase only when you mean to

A full install can overwrite application and persistent partitions. Read the flasher mode carefully, especially if you already have Wi-Fi credentials or device configuration stored on the board.

COMMAND LINE

Build and flash it yourself.

For development, the repository uses ESP-IDF. A normal build/flash cycle is intentionally boring.

idf.py set-target esp32
idf.py build
idf.py -p /dev/ttyUSB0 flash monitor

On Windows, replace the port with something such as COM4. The exact port depends on your USB-to-serial interface.

BROWSER REQUIREMENTS

Web Serial has rules.

Supported desktop browsers

Use a current Chromium-based browser such as Chrome or Microsoft Edge for the browser flasher. The project flasher and Espressif's Launchpad both depend on Web Serial.

HTTPS required

Web Serial works in a secure context. GitHub Pages provides HTTPS, which is why the project flasher is hosted there.

Not iPhone Safari

Do the flashing from a desktop computer. Mobile browsers, especially iOS browsers, do not provide the Web Serial workflow required here.

Trust rule: if you are unsure about a random ESP32 flashing website, do not upload your firmware or connect your board to it. Prefer this project's own GitHub Pages flasher, Espressif's official ESP Launchpad, or the official ESP-IDF / esptool toolchain.
