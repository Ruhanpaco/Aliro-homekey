NFC Reader

The PN532 is the only frontend with a driver. Reserved and input-only pins are not offered, and nothing may be assigned twice.

Pins are stored and validated now; no chip driver is written yet, so the reader still runs with no radio.

Connect to Wi-Fi

Joins the network straight away and tells you the address it landed on. The setup access point stays up while it tries, so a wrong password is reported rather than discovered after a reboot.

Network

Stored credentials, applied on the next restart. Connecting above fills these in for you.

At least 8 characters, or blank for an open network.

Security

A username and password for this interface. Without one, anyone who can reach this address can change the configuration, unlock the door and install firmware.

This reader has no login. Anyone on the network can reach /api/unlock and /api/ota.

At least 8 characters. The browser asks for these on the next request, so keep them somewhere before saving. There is no way in without them except erasing the configuration over USB.

Maintenance

Reset erases the stored configuration, including Wi-Fi credentials. The reader comes back on its setup access point.
